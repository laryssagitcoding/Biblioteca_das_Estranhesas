# 📚 Biblioteca das Estranhezas

> Uma historinha interativa recheada de mistérios, decisões e caminhos para explorar!

🔗 **Acesse a história:** [laryssagitcoding.github.io/Biblioteca_das_Estranhesas](https://laryssagitcoding.github.io/Biblioteca_das_Estranhesas/)

---

## 📖 Sobre a História

A **Biblioteca das Estranhezas** é um projeto de narrativa interativa que transporta o leitor para um acervo misterioso repleto de segredos, tomos antigos e acontecimentos peculiares. 

À medida que a história avança, o leitor toma decisões que alteram os rumos da narrativa, criando uma experiência envolvente de leitura e exploração do desconhecido.

---

## 🎯 Objetivos do Projeto

* Criar uma experiência lúdica e imersiva de *storytelling* digital.
* Praticar a lógica de programação (tomada de decisões e caminhos na narrativa).
* Aplicar conceitos de desenvolvimento web e estilização temática aprendidos na **Alura**.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Estruturação do texto e das opções da história
* **CSS3** — Design, ambientação visual e responsividade
* **JavaScript** — Lógica para a troca de cenários e fluxo das escolhas

---

## 🎮 Como Jogar / Explorar

1. Clique no link do projeto para iniciar a história.
2. Leia o trecho apresentado em cada página.
3. Escolha uma das opções disponíveis para decidir o próximo passo da sua jornada.
4. Descubra todos os caminhos e segredos escondidos na biblioteca!
